Small uppercase status / meta tag (e.g. "Draught", "Posted nearby", "Worth the Trip"). For drink-type categories use `DrinkChip` instead — it carries the accent-colour system.

```jsx
<Tag tone="cream">Draught</Tag>
<Tag tone="gold">Worth the Trip</Tag>
<Tag tone="rust" pill={false}>Flat</Tag>
```

Tones: neutral · cream · gold · sage · rust.
