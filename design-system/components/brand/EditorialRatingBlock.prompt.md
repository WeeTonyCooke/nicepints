The signature score treatment — the single largest element on a feed or hero card. Big Playfair numeral with the decimal as a raised superscript, a gold hairline rule beneath, and a one-word verdict (Exceptional / Excellent / Very Good / Good, shown only at 6.5+). Built to sit top-right over a pint photo.

```jsx
<EditorialRatingBlock score={9.4} size="hero" />
<EditorialRatingBlock score={8.1} size="feed" />
```

Always cream (never tinted) so it reads on any photo; the rule carries the gold.
