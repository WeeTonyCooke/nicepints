The Nice Pints wordmark — Playfair Display black with "Pints" set gold italic. The `header` size leads with the inlined pint mark; `compact` is the uppercase muted eyebrow used above screen titles. `PintMark` is the standalone glass icon.

```jsx
<BrandWordmark size="header" />        {/* mark + wordmark */}
<BrandWordmark size="display" showIcon={false} />
<BrandWordmark size="compact" />      {/* NICE PINTS eyebrow */}
<PintMark size={42} />
```

Gold appears on "Pints" only — never elsewhere in the lockup.
